二、初始编译错误分析
--------------------------------------------------------------------------------
首次执行 dotnet build AiApplication.sln 共发现 4 轮编译错误，逐轮修复：

【第 1 轮：4 个错误】ApplicationServiceExtensions.cs
    error CS0246: 未能找到类型或命名空间名"IRagService"
    error CS0246: 未能找到类型或命名空间名"RagService"
    error CS0246: 未能找到类型或命名空间名"IMcpService"
    error CS0246: 未能找到类型或命名空间名"McpService"
原因：用户在 AddApplication() 中新增了 IRagService→RagService 和
      IMcpService→McpService 的注册，但：
      (1) 缺少 using AiApplication.Application.RAG / MCP 指令；
      (2) RagService / McpService 实现类不存在（只有接口）。

【第 2 轮：2 个错误】Infrastructure 层空壳文件
    error CS0246: 未能找到类型或命名空间名"IPromptTemplateRepository"
    error CS0246: 未能找到类型或命名空间名"IPromptRenderer"
原因：FilePromptTemplateRepository.cs 和 PromptRenderer.cs 缺少
      using AiApplication.Application.Abstractions.Prompt 指令。

【第 3 轮：4 个错误】InfrastructureServiceExtensions.cs
    error CS0246: 未能找到类型或命名空间名"FilePromptTemplateRepository"
    error CS0246: 未能找到类型或命名空间名"PromptRenderer"
    error CS0246: 未能找到类型或命名空间名"AppDbContext"
    error CS1061: "IServiceCollection"未包含"AddDbContext"的定义
原因：用户在 AddInfrastructure() 中新增了三处注册：
      (1) IPromptTemplateRepository → FilePromptTemplateRepository
      (2) IPromptRenderer → PromptRenderer
      (3) AddDbContext<AppDbContext>()
      但缺少对应 using 指令，且 AddDbContext 需要 EF Core 包，
      AppDbContext 需继承 DbContext。

--------------------------------------------------------------------------------
三、修复措施
--------------------------------------------------------------------------------

1. 创建 RagService / McpService 实现类
   ─────────────────────────
   在 RagService.cs 中追加 RagService 类（占位实现，返回空列表）：
       public sealed class RagService : IRagService
       {
           public Task<IReadOnlyList<string>> RetrieveAsync(...) =>
               Task.FromResult(System.Array.Empty<string>());
       }
   在 McpService.cs 中追加 McpService 类（占位实现，返回空列表）：
       public sealed class McpService : IMcpService
       {
           public Task<IReadOnlyList<string>> ExecuteToolsAsync(...) =>
               Task.FromResult(System.Array.Empty<string>());
       }
   说明：占位实现使项目可编译；后续接入向量库/MCP 协议时替换为真实逻辑。

2. 修复 ApplicationServiceExtensions.cs using 指令
   ───────────────────────────────────────
   新增：
       using AiApplication.Application.MCP;
       using AiApplication.Application.RAG;

3. 修复 Infrastructure 层空壳文件 using 指令
   ─────────────────────────────────────
   FilePromptTemplateRepository.cs：新增 using AiApplication.Application.Abstractions.Prompt;
   PromptRenderer.cs：新增 using AiApplication.Application.Abstractions.Prompt;

4. 添加 EF Core 包并实现 AppDbContext
   ────────────────────────
   csproj 新增包引用：
       <PackageReference Include="Microsoft.EntityFrameworkCore" Version="3.1.32" />
   AppDbContext.cs 改为继承 DbContext：
       public class AppDbContext : DbContext
       {
           public AppDbContext(DbContextOptions<AppDbContext> options) : base(options) { }
       }

5. 修复 InfrastructureServiceExtensions.cs using 指令
   ────────────────────────────────────────
   新增：
       using AiApplication.Infrastructure.Persistence;
       using AiApplication.Infrastructure.Prompt.Rendering;
       using AiApplication.Infrastructure.Prompt.Repository;
       using Microsoft.EntityFrameworkCore;
