--------------------------------------------------------------------------------
三、关键决策与说明
--------------------------------------------------------------------------------

1. 为什么需要添加 NuGet 包引用？
   ───────────────────────
   - IServiceCollection → Microsoft.Extensions.DependencyInjection.Abstractions
   - IConfiguration → Microsoft.Extensions.Configuration.Abstractions
   - services.Configure<T>(section) → Microsoft.Extensions.Options.ConfigurationExtensions
   - IHttpClientFactory / AddHttpClient<T> → Microsoft.Extensions.Http
   这些包是 .NET Core DI 体系的标准组件，ASP.NET Core Web SDK 已隐式包含，
   但 Application / Infrastructure 作为类库项目需显式引用。
   版本统一选 3.1.32，与目标框架 netcoreapp3.1 对齐。

2. AddApplication() 注册了什么？
   ───────────────────────
   仅注册 IChatService → ChatService（单例）。
   ChatService 的依赖（IAiClientProvider、IPromptBuilder）由 Infrastructure 层注册；
   可选依赖（IRagService、IMcpService）未注册时 ChatService 以 null 容忍跳过。
   这是"应用层只关心业务编排，不关心基础设施实现"的分层原则体现。

3. AddInfrastructure(configuration) 注册了什么？
   ─────────────────────────────────────
   (1) Options 绑定：从 appsettings.json 的 "AI:OpenAI" / "AI:Claude" / "AI:DeepSeek"
       节点绑定到对应 Options 类。同时注册 IOptions<T>（支持运行时变更通知）与
       T 单例（便于客户端构造函数直接注入，无需在客户端代码中依赖 IOptions）。
   (2) HttpClient 注册：通过 AddHttpClient<T> 注册三个客户端的 HttpClient，
       由 IHttpClientFactory 管理生命周期，避免直接 new HttpClient() 的 DNS 老化问题。
       配置回调中从 Options 读取 BaseUrl 设置 HttpClient.BaseAddress。
   (3) 响应解析器：注册三个 ResponseParser 为单例。
   (4) AI 客户端：三个客户端分别注册为 IAiClient 的多实现（Transient），
       AiClientProvider 通过 IEnumerable<IAiClient> 在构造时自动收集所有注册实例。
   (5) 路由器：IAiClientProvider → AiClientProvider（单例）。
   (6) 提示词构建器：IPromptBuilder → GeneralChatPromptBuilder（单例，默认实现）。

4. 为什么同时注册 IOptions<T> 和 T 单例？
   ────────────────────────────────
   客户端构造函数签名是 OpenAiClient(HttpClient, OpenAiOptions, IAiResponseParser=null)，
   直接接受 OpenAiOptions 而非 IOptions<OpenAiOptions>。这是为了：
   - 保持客户端与 DI 框架解耦（可脱离 IOptions 单独测试）。
   - 简化客户端内部代码（无需每次调用 .Value）。
   因此在 DI 中额外注册一个 T 单例工厂，从 IOptions<T>.Value 解析后注入。

5. 多实现注册（IAiClient）如何工作？
   ────────────────────────
   对同一接口 IAiClient 注册三次（OpenAiClient / ClaudeClient / DeepSeekClient），
   DI 容器在解析 IEnumerable<IAiClient> 时会返回全部三个实例。
   AiClientProvider 构造函数接受 IEnumerable<IAiClient>，自动收集并按 Provider 属性
   建立路由字典。这是 ASP.NET Core 多实现注册的标准模式。

【Infrastructure/DependencyInjection/InfrastructureServiceExtensions.cs】
    public static class InfrastructureServiceExtensions
    {
        public static IServiceCollection AddInfrastructure(
            this IServiceCollection services, IConfiguration configuration)
        {
            // 1. Options 绑定（IOptions<T> + T 单例）
            RegisterOptions<OpenAiOptions>(services, configuration, OpenAiOptions.SectionName);
            RegisterOptions<ClaudeOptions>(services, configuration, ClaudeOptions.SectionName);
            RegisterOptions<DeepSeekOptions>(services, configuration, DeepSeekOptions.SectionName);

            // 2. HttpClient（IHttpClientFactory）
            services.AddHttpClient<OpenAiClient>(ConfigureOpenAiHttpClient);
            services.AddHttpClient<ClaudeClient>(ConfigureClaudeHttpClient);
            services.AddHttpClient<DeepSeekClient>(ConfigureDeepSeekHttpClient);

            // 3. 响应解析器
            services.AddSingleton<OpenAiResponseParser>();
            services.AddSingleton<ClaudeResponseParser>();
            services.AddSingleton<DeepSeekResponseParser>();

            // 4. 三个 AI 客户端注册为 IAiClient 多实现
            services.AddTransient<IAiClient>(sp => sp.GetRequiredService<OpenAiClient>());
            services.AddTransient<IAiClient>(sp => sp.GetRequiredService<ClaudeClient>());
            services.AddTransient<IAiClient>(sp => sp.GetRequiredService<DeepSeekClient>());

            // 5. 路由器
            services.AddSingleton<IAiClientProvider, AiClientProvider>();

            // 6. 提示词构建器
            services.AddSingleton<IPromptBuilder, GeneralChatPromptBuilder>();

            return services;
        }
    }

【Api/Startup.cs】ConfigureServices 方法：
    public void ConfigureServices(IServiceCollection services)
    {
        services.AddApplication();
        services.AddInfrastructure(Configuration);
        services.AddControllers();
    }
