一、任务背景与需求分析
------------------------------------------------------------

用户要求：
  在 ToolSchemaBuilder.ToolSchema（实为 Build 方法）中：
  1. 填充 ToolSchemaProperty 的 Description 值
  2. 填充 ToolSchema 的 Required 值

需求理解：
  Build 方法通过反射从请求类型（RequestType）构建 ToolSchema。
  原实现仅设置了每个属性的 Type，未读取 Description 和 Required。
  需要通过反射读取属性上的特性（Attribute）来填充这两个字段。

三、修改方案
------------------------------------------------------------

在 ToolSchemaBuilder.Build 方法的 foreach 循环中，对每个属性：

1. 读取 Description：
   使用 property.GetCustomAttribute<DescriptionAttribute>()
   获取 System.ComponentModel.DescriptionAttribute
   若存在，将 descriptionAttribute.Description 赋值给 schemaProperty.Description

2. 读取 Required：
   使用 property.GetCustomAttribute<RequiredAttribute>()
   获取 System.ComponentModel.DataAnnotations.RequiredAttribute
   若存在，将 property.Name 加入 schema.Required 列表

3. 新增 using 引用：
   using System.ComponentModel;          // DescriptionAttribute
   using System.ComponentModel.DataAnnotations;  // RequiredAttribute

四、修改后的完整代码
------------------------------------------------------------

using System;
using System.Collections.Generic;
using System.ComponentModel;
using System.ComponentModel.DataAnnotations;
using System.Reflection;

namespace AiApplication.Application.Tools.Schema
{
    public static class ToolSchemaBuilder
    {
        public static ToolSchema Build(Type requestType)
        {
            if (requestType == null)
            {
                throw new ArgumentNullException(nameof(requestType));
            }

            ToolSchema schema = new ToolSchema
            {
                Type = "object",
                Properties = new Dictionary<string, ToolSchemaProperty>(),
                Required = new List<string>()
            };

            PropertyInfo[] properties = requestType.GetProperties(
                BindingFlags.Instance |
                BindingFlags.Public);

            foreach (PropertyInfo property in properties)
            {
                ToolSchemaProperty schemaProperty =
                    new ToolSchemaProperty();

                schemaProperty.Type =
                    TypeMapper.Map(property.PropertyType);

                // 读取 [Description] 特性，填充属性描述
                DescriptionAttribute descriptionAttribute =
                    property.GetCustomAttribute<DescriptionAttribute>();
                if (descriptionAttribute != null)
                {
                    schemaProperty.Description =
                        descriptionAttribute.Description;
                }

                // 读取 [Required] 特性，收集必填属性名
                RequiredAttribute requiredAttribute =
                    property.GetCustomAttribute<RequiredAttribute>();
                if (requiredAttribute != null)
                {
                    schema.Required.Add(property.Name);
                }

                schema.Properties.Add(
                    property.Name,
                    schemaProperty);
            }

            return schema;
        }
    }
}

七、设计评价与注意事项
------------------------------------------------------------

1. 特性选择合理性：
   - DescriptionAttribute（System.ComponentModel）是 .NET 标准的描述特性，
     广泛用于属性、枚举等成员的描述声明，选择合理。
   - RequiredAttribute（System.ComponentModel.DataAnnotations）是数据注解标准特性，
     常用于模型验证表示必填，选择合理。

2. 与现有代码一致性：
   - WeatherRequest 已使用这两个特性，说明项目已有此约定
   - 修改使 Build 方法与请求类型的特性声明保持语义一致

3. 对 OpenAI API 的影响：
   - OpenAI Function Calling 的 parameters JSON Schema 标准中，
     "description" 和 "required" 是标准字段
   - 填充后可使 AI 模型更准确地理解参数含义与必填约束，
     提升工具调用的准确率

4. 潜在扩展：
   - 如需支持枚举描述（EnumMember/Description），可在 TypeMapper 或 Build 中扩展
   - 如需支持数组元素的 items schema，可进一步扩展 ToolSchemaProperty
   - 如需支持嵌套对象的 properties，可递归调用 Build

5. 线程安全性：
   - ToolSchemaBuilder 为静态类，Build 为静态方法，无共享状态，线程安全
